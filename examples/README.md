# Render examples

This folder exercises every rendering feature supported by AWiki Exporter, so
you can validate HTML preview, Word export and PDF export end to end.

Use it in two ways:

- **Open folder** in the Workspace to load every file below recursively.
- Point a **GitHub wiki** at this repository with **Docs Path** = `examples`.

## Index

| File | Feature |
| --- | --- |
| [01-text-and-formatting.md](01-text-and-formatting.md) | Headings, emphasis, links, quotes, rules |
| [02-tables.md](02-tables.md) | Pipe tables, alignment, inline formatting in cells |
| [03-code.md](03-code.md) | Inline code, fenced blocks, many languages |
| [04-alerts.md](04-alerts.md) | GitHub alerts (note/tip/warning/important/caution) |

| [08-emoji-and-frontmatter.md](08-emoji-and-frontmatter.md) | YAML front matter + emoji shortcodes |
| [09-images-and-badges.md](09-images-and-badges.md) | PNG, SVG badges, WebP, inline SVG, data URI |
